# Limitations and Ethical/Research Notes

- Source cards are summaries, not substitutes for the original papers.
- Different datasets and hardware make direct numerical comparisons potentially misleading.
- LLM-generated synthesis is probabilistic and must be checked before inclusion in an academic thesis.
- The system does not diagnose real plants and should not be presented as a validated agricultural decision-support system.
- No API key is stored in the repository.
- The application should be deployed only after testing secrets and rate limits in the chosen hosting environment.
