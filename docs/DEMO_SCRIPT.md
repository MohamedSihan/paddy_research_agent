# 5-Minute Demonstration Script

1. Open the Streamlit application.
2. Explain the research question and why a research-support agent was chosen rather than a second disease classifier.
3. Enter the default question and run the workflow.
4. Show the **Agent trace** tab to demonstrate three agents and structured messages.
5. Show **Retrieved evidence** and explain the source IDs and similarity scores.
6. Show **Reviewer** and explain the reflection/critic pattern.
7. Enter a retrieval-only query such as “hybrid CNN vision transformer edge deployment”.
8. Run `python tests/evaluate_retrieval.py` and show the five-query benchmark.
9. Explain that exact latency/model-size numbers for the research paper must be measured experimentally and are not fabricated by this support tool.
10. Show `.env.example`, README, architecture document and GitHub workflow.
